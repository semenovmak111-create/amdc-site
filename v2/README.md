# Сайт для АМДЦ — версия 2

Персональное предложение для АМДЦ (ул. Орбели, 19): конверсионный сайт на 14 направлений за 10 дней.

Статичная страница без сборки и библиотек: `index.html`, `assets/style.css`, `assets/main.js`.

- Блок 5 — карусель «Что даёт сайт» (7 слайдов: стрелки, вкладки, точки с автопрокруткой, свайп, клавиши ← →).
- Блок 10 — калькулятор «Ваши цифры» (просмотры карточки, поиск, средний чек, доходимость → воронка и выручка за месяц / квартал / год).

Голосовое сообщение в блоке 16 ожидается по пути `assets/audio/voice.m4a`.

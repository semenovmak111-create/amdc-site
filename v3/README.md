# Сайт для АМДЦ — версия 3

Тот же смысл и порядок блоков, новый дизайн: белая база, блоки-карточки со скруглением,
индиго-градиенты, схемы-дорожки, подписи разделов в скобках, первый экран с вырезами под меню и контакты.

Статичная страница без сборки и библиотек: `index.html`, `assets/style.css`, `assets/main.js`.

- Блок 5 — карусель «Что даёт сайт» (7 слайдов: стрелки, вкладки, полоса автопрокрутки, свайп, клавиши ← →).
- Блок 10 — калькулятор «Ваши цифры» (карточка, поиск, средний чек, доходимость → воронка и выручка за месяц / квартал / год).

Голосовое сообщение в блоке 16 ожидается по пути `assets/audio/voice.m4a`.
